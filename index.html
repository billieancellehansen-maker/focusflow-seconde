FocusFlow Seconde

Application de révision pour les élèves de seconde.

Présentation

FocusFlow Seconde est une application Python avec interface graphique. L'utilisateur choisit une matière, répond à un quiz et obtient un score final.

Fonctionnalités

  • Accueil interactif
  • Choix de matière
  • Questions de quiz
  • Score final
  • Bouton recommencer

Technologies utilisées

  • Python
  • Tkinter
  • HTML / CSS
